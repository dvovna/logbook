This page helps you set up time off as time: the project each kind of leave is logged on, and how many hours a day off counts. Only admins change these settings.

Once a leave type has a project, people whose time off of that type is approved can log it as time with one click. How that works for them is in [Time off as time](/logbook/docs/everyone/time-off-as-time/).

## Set it up

1. Open **More** → **Projects**. Create the projects first if you don't have them yet; see [Projects and clients](/logbook/docs/finance/projects-and-clients/).
2. Click **🌴 Time off projects**.
3. In **Hours in a working day**, enter how many hours a day of time off counts, in 15-minute steps: `8`, or `7.5`. The default is 8.
4. Choose a project for each leave type you want logged: **🏖️ Annual leave**, **🎁 Bonus day**, **🤒 Sick leave**, **💸 Unpaid leave**. Leave a type on **Not logged** to keep it out.
5. Click **Save**. Projects says the settings were saved.

The form offers the workspace's active projects, any of them. Other leave is never logged.

## What Projects shows

Above the project list, Projects says what is set, for example:

> Annual leave → Holidays · Sick leave → Sick days · 8h a day

When no type has a project, it says "No leave type has a project yet." Only admins see this part of Projects.

## What it changes

- When a request of a type with a project is approved, the requester's DM about it has a button such as **Log 40h to Holidays**. The click logs one approved entry per working day of the time off, on that project, at the hours of a working day.
- When HR or an admin creates a request as approved, or edits one into approved, the requester gets the offer in a DM of its own.
- A type with no project gets no button.

A click logs on the project and at the hours set at the time of the click, also from a button sent before a change. Time already logged stays as it is.

## When a project is archived

A leave type whose project is archived counts as unset:

- Projects leaves it out of what is set.
- Its time off gets no offer. A button sent before logs nothing and says the time off has no project to log on.
- The form shows the field empty. Saving the form clears it; choose another project to log that type again.

Projects are archived, never deleted, so a mapping ends by archiving its project or by setting the type to **Not logged**.
