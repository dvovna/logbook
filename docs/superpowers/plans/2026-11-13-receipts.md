# Receipts for reimbursements: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** People send receipts for a reimbursement (gym, lunches) to Logbook in Slack; Admin and Finance check them on one screen, see who sent none, and download the month.

**Architecture:**
- A domain module `src/receipts` holds reimbursements, receipts, their files (behind `ReceiptFileStore`, Postgres `bytea`), decisions, opt-outs and the month's overview. It imports nothing from `src/slack`.
- The Slack side is `src/slack/receipts` (the DM messages: a received file, a rejection, reminders, Open and Download) and two tabs, `src/slack/tabs/receipts` (Finance's screen and Reimbursements) and `src/slack/tabs/my-receipts`.
- A file arrives through the existing `file_shared` job; everything sent to people later is a job.

**Tech Stack:** NestJS 11, TypeScript, Kysely 0.28 on Supabase Postgres, pg-boss 10, `fflate` (new dependency, the ZIP), Jest (unit and `test/integration`).

**Spec:** `docs/superpowers/specs/2026-11-13-receipts-design.md`

## Global Constraints

- `CLAUDE.md` is binding: interfaces start with `I`; explicit member accessibility; imports by `@modules/…`, `@common/…` or `src/…`; domain code doesn't import `src/slack`; comments only for what isn't obvious; every repository query scoped by `slack_team_id`.
- Multi-row writes are `TransactionService` transactions; no Slack call inside one. A job that follows a change is enqueued in the change's transaction (`emitAsync` + listener with `suppressErrors: false`).
- Receipts, their amounts and files are readable only by their owner and `BILLING_ROLES` (Admin, Finance). Every ID from the client is checked in the service.
- A file is at most 10 MB (`MAX_RECEIPT_FILE_BYTES`). Accepted names: `/\.(jpe?g|png|heic|webp|gif|pdf)$/i`.
- At most 10 active reimbursements per workspace (`MAX_ACTIVE_REIMBURSEMENTS`): Slack's checkbox group takes 10 options.
- Monthly periods only; a month is the `YYYY-MM-01` string. `due_day` is 1–28, in the month after.
- Amounts are whole cents in the workspace's currency (`toCents`, `formatMoney`); an amount is above 0 and at most 1,000,000.00.
- File bytes are never logged, sent to Sentry or selected by a list query: only `ReceiptFileStore` reads `receipt_files`.
- Text people typed (comment, reason, file name, reimbursement name) goes through `escapeMrkdwn`.
- Slack limits: 5 elements per actions block (`splitIntoRows`), 100 blocks per view, no table in a modal; statuses and their icons come from `labels.ts`.
- New tables: `slack_team_id` with `ON DELETE CASCADE`, RLS enabled, an index starting with each foreign key's columns, in the same migration. Run `pnpm db:init` and `pnpm db:types` after it.
- Bot copy is English.
- Round-trip budgets in `test/integration/round-trips.int-spec.ts`: Home may grow only in `statements`, by reads placed beside its others in `Promise.all`; `roundTrips` never grows.
- Commits are short imperative one-liners with no trailers.
- A change people notice comes with its docs page (Task 12).

## Review Focus

1. **Several photos sent in one message** (a phone's share sheet). Each file becomes its own draft with its own "Add details" message. Test: Task 4.
2. **The same file delivered or sent twice** (Slack's retry of `file_shared`, a double tap, the same photo next week). One receipt; the second time the person is told it is already there. Tests: Task 3, Task 4.
3. **An amount typed the way people type** (`45,50`, `45.5`, ` 45 `, `€45`). `45,50` and `45.5` are 45.50; a currency sign, `0`, a negative or more than 1,000,000 is refused at the field. Test: Task 4.
4. **Two Finance people deciding one receipt at once.** One decision is made; the other click is told the receipt was already decided, and one rejection DM goes out. Test: Task 6.
5. **A reimbursement archived while its form is open or a draft waits.** Submitting is refused at the Reimbursement field; the draft stays. Test: Task 3.
